# T10 原生 Bootstrap 首个实现

日期：2026-10-20。T10 状态 IN_PROGRESS，退出路径子项已验证。机器记录见 [源码与验证证据](t10-bootstrap-evidence.json)。本轮使用用户明确批准的固定控制树，不改变控制器或 registry。

## 实现

- bootstrap-api：32 字节平台退出描述符；固定宽度字段、版本/尺寸/预留位校验、借用上下文和回调。C 静态断言核对 Assembly 共享布局。
- bootstrap：仅消费注入函数表，校验输入并转发退出码；非法输入返回 -1，退出回调意外返回时返回 -2。无平台私有符号依赖。
- platform-linux：SysV 参数转 Linux exit_group 系统调用，无 libc。系统调用指令只在平台模块。
- composition：独立静态组合入口，初始化接口表、调用通用 Bootstrap；失败路径非零退出，入口栈对齐且根帧可终止回溯。

四份源码位于已批准的外部 candidate/src/ 下，未塞入根设计树的 gate/文档。可点击的绝对位置记录在 JSON；可恢复 tar 快照与摘要一并保留。根控制器及参考仓库没有被修改。

## 实际验证

固定镜像、只读控制器/候选、断网环境下完成 debug/release 构建；重新验证完整矩阵、输入和保留产物。执行时将 ELF 复制为可执行副本并校验内容摘要，在另一个清空环境、断网且不挂载用户目录的 namespace 运行；不修改原始构建证据。

两个模式分别验证：基线退出 0；7 类非法输入与返回回调的 ABI 边界；替代 Linux 单线程退出提供者退出 0。三个变体均复验构建产物。替换提供者不改通用消费者源文件，组合图仍由固定登记约束；这不是通用插件宿主实现。

未知源码被全树扫描拒绝；通用消费者直接调用未声明的平台提供者被符号/依赖检查拒绝；二进制篡改被产物复验拒绝。所有原始输入、命令、回执及诊断位于 JSON 指定目录。

ELF 原始尺寸：debug 11712 字节，release 9344 字节。没有 strip 规避统计，不含模型、TLS、工具、会话或 TUI；这些尺寸不能当作完整 Agent 预算。未基线指标保持 UNBASELINED。
