# 原生候选源码准入与构建矩阵

状态：候选控制面实现，未批准生产源码。现有 `check.py` 的 design-only 规则不变；`governance/native-admission.json` 仍为空登记，实际项目不能因此开始加入生产 `.c`/`.S`。

## 权威与输入

`tools/gates/admission.py` 从指定控制器读取登记、工具链和规则，要求外部策略摘要及完整控制器文件树摘要。候选中的控制、检查器、测试和 AGENTS 内容/权限必须匹配控制版本；候选自行修改登记、工具链或伪造 PASS 脚本会在构建前拒绝。

控制器是仅含登记文档/控制文件/检查工具的独立快照；候选可以额外拥有该控制版本明确登记的原生文件。两者分别扫描，额外文件即使不是代码扩展名、额外空目录、软链接、缺失文件均拒绝。`references/` 和 `.git/` 不进入编译；登记不能指向它们。

CLI 必须从指定控制器的 admission.py 执行。摘要需要由外部可信流程提供；本地自己填写摘要只表示演练，不形成独立信任或发布批准。

## 登记字段

顶层 `pangu.native-admission.v1` 明确 `phase=CANDIDATE_NOT_APPROVED`、`target=linux-x86_64`、受控工具链文件、模块数组、服务定义数组和必需构建数组。未知字段和自行声明 APPROVED 拒绝。

模块保留 ID、角色、作用域、文件/公开头、允许依赖，并补全：

- 源码根、责任、非职责；边界理由及已登记的审查材料路径。
- 实际语言集合、公开符号、平台、静态交付方式、参与的组合和激活条件。
- 服务提供/消费与版本；第三方依赖清单。当前实现不开放第三方原生库、DSO、C++ 或其他方言，不能把尚未实现的能力默认放进构建。
- activate/dispose 符号、状态/资源所有者、线程与回调规则。声明只供核对和审查，不等于生命周期已实测。
- 按 debug/release 登记的对象字节预算及测量计划；无基线必须明确用 null，不能自动算性能通过。

`dependencies` 是允许边，`required_modules` 是其中每个组合都必须装入的子集。它们不能混为一谈：允许两个替代提供者不等于每次必须同时链接两个。每个构建的 required_modules 闭合，实际包含和链接仍须属于选中的允许边。每个登记模块必须被至少一个必需构建覆盖，compositions 必须与实际矩阵一致，不能把未编译模块藏在登记里。

低层 host/foundation/platform 不能依赖 plugin/client；接口模块不能登记实现翻译单元或提供者。角色、职责和边界理由仍须独立审查；机器无法证明文本中的“基础服务”不是业务伪装。

构建登记 ID、作用域、选中模块、固定 debug/release 两模式、受控入口、服务绑定和最终 ELF 字节预算。命令行不能只挑较易通过的模式或跳过必需组合。服务组合使用既有 service_graph 解析；缺必需服务、重复绑定或版本冲突拒绝。真实运行绑定与资源清理仍归 T08/T13。

## 执行及汇总

每个组合只暂存其登记源码，保持相对路径和输入摘要；未选提供者不会被顺手链接。随后运行真实 Clang/GNU as 输入检查、符号/最终 ELF 校验，再独立复验保留产物。源码和控制器在整个矩阵前后核对。程序只构建、分析产物，不执行候选入口。

对象字节按所属模块重新统计，ELF 字节来自实际文件；两类预算独立，不用对象总量冒充运行 RSS。已登记上限超出会拒绝，无基线记入清单。只签录完成全部必需构建的 admission.json；失败可以留下局部诊断，但没有完整矩阵回执。

`--verify-receipt-sha256` 复验整份矩阵：核对外部回执摘要、源码/控制器/登记、完整组合与模式、全部产物目录、各 build.json 及其对象/符号/ELF；重新统计尺寸和未建立基线项。伪造大小、删一个模式、遗漏预算或拿源码已变化的旧结果都拒绝。

空登记输出 native_matrix=NOT_RUN 和 BLOCKED，绝不零用例通过。完整候选矩阵通过仍为 status/release=BLOCKED；ABI、运行时、性能和独立批准没有被本入口替代。

## 隔离入口

`toolchain_image.py run --job native-admission` 仅调度固定 admission.py，不能传任意脚本。镜像必须匹配该登记指定的工具链；控制器和候选只读、断网、不挂载用户目录，输出独立。原有 self-tests 作业仍只验证控制器自测，不能算候选产品已经构建。

直接调用 admission.py 的回执明确标记执行环境未经该入口证明；只有外层隔离回执绑定了实际 namespace 设置与内部回执摘要。隔离机制及摘要不替代 GitHub 检查发布者的独立权限。

```sh
python3 -B tools/gates/admission.py --controller <控制器目录> --candidate <候选目录> --policy-sha256 <策略摘要> --controller-sha256 <控制器树摘要> --output <新外部目录>
python3 -B tools/gates/admission.py --controller <控制器目录> --candidate <候选目录> --policy-sha256 <策略摘要> --controller-sha256 <控制器树摘要> --output <保留目录> --verify-receipt-sha256 <admission.json摘要>
```

候选采集/复验成功退出码 2，拒绝退出码 1。测试用临时模块和工具链正反例，不登记生产模块。两个静态提供者切换得到 7/9，证明的是选中组合、符号边和固定消费者样例，不能称为原生插件宿主或 Agent 已实现。

本轮还修正了嵌套目录调试元数据：Clang 的第一条未编号 `.file` 是 primary input 的 basename，GNU as 将其列入 --MD，造成合法嵌套源码被误报。只将这条已确认属于编译器的元数据规范到真实登记路径，并记录前后摘要；不删除依赖、不猜路径，也不豁免实际 .include/.incbin。编号 DWARF 行表保留，汇编输入反例继续必测。
