## 模块与输入检查

`module_graph.py` 校验模块清单，`compile_inputs.py` 执行实际编译和输入交叉验证。product/test/development 分离，接口不能依赖实现，宿主不能直接依赖业务/客户端；跨模块只能包含直接依赖的公开头。当前保守地检查完整传递包含集合，不能把它称为直接 include 边的精确还原。未知文件、缺失登记、软链接、循环和输入变化均拒绝。

参考 Pi 的 `scripts/check-runtime-deps.mjs` 和 `check-entry-graphs.mjs`：声明必须与实际依赖交叉检查，公开入口形成约束。原生检查采用编译器/汇编器输出和对象符号，不只搜索源文本。

新增反例发现 Clang 常规 `-MD` 不记录 GAS `.include`/`.incbin`。因此 `native_build.py` 采用显式两阶段流程：Clang 对 C 输出 GNU as 兼容汇编、对 `.S` 预处理；固定 GNU as 用 `--MD` 收集实际汇编输入。C 内联汇编隐藏的 `.incbin` 也受相同检查。生成中间汇编是唯一明确登记的临时输入例外，其摘要绑定产生它的编译阶段；原始两阶段依赖与完整命令保存在回执。未知 `.inc`/二进制输入拒绝，已登记本模块头可被汇编包含并进入证据。

旧 `toolchain.py`/C17 探针仅作早期局部测试，不作为完整汇编输入验证或另一条生产放行通道。新入口只接受单一已登记语言方案，未知模式/参数、响应文件、插件或脚本均拒绝。源码实参加 `./` 前缀，防止连字符文件名成为编译参数。

## 符号、产物与服务

`link_graph.py` 在真实目标文件上拒绝私有符号调用、未声明依赖、重复定义、缺失导出和未解析外部调用；缺省不开放系统符号。弱符号/common/IFUNC 等未实现的语义拒绝。内部跨文件符号可在本模块解析，公开符号表只约束跨模块使用，不证明最终 DSO 导出已经稳定。

`native_build.py` 保留对象、ELF、map、反汇编和 build.json，并支持用外部回执摘要复验：核对文件全集、重算字节、检查源码和策略、重新解析 ELF、再次以保留对象检查符号及链接。篡改任何产物或回执不能沿用旧结果。非 platform/host 对象中出现直接 syscall/sysenter/int 指令时拒绝；这不是对可信原生插件的 OS 沙箱证明。

`service_graph.py` 参考 Harness/Cordis 的服务注入：消费者依赖接口定义而不依赖具体提供者，替换只改组合。必需服务缺失时输出 PENDING 且不给激活顺序；可选缺失必须声明 disable-feature。绑定提供者唯一、版本必须精确匹配，已选可选边也参与拓扑排序。输出激活/反向清理计划，但不把计划当作初始化失败回滚或异步资源清理的运行证明。原生轨迹交叉验证由 T08/T13 接入，不循环要求 T05 先实现生产宿主。

## 回执、统一执行与隔离

`receipt.py` 使用指定控制器的策略检查候选，而不执行候选检查脚本。control/gate/gate-test/instructions 内容和权限必须匹配控制版本。回执绑定全部登记文件、解释器及策略，要求外部回执摘要复验；源码、权限、控制器、回执变化均拒绝。输出位于输入树之外且不能覆盖旧证据。

`runner.py` 固定调度十五个门禁套件，逐套保存命令、返回码、原始 stdout/stderr 和计数。零测试、跳过、预期失败、意外成功、异常、超时、失败或执行期间输入变化均拒绝。回执明确记录候选原生产品验证 NOT_RUN；控制器自测包含的原生样例不是产品验证。

`controller_probe.py` 复制两个独立目录，实测删除检查器、伪造 PASS、删策略检查登记、增加未知源码、替换工具链这五种攻击。参考目录不复制。其早期实证位于 `PanGu-artifacts/gates/t05-separated-emjjxz8_/experiment/experiment.json`，绑定的是当时的完整快照。

`toolchain_image.py` 将工具、动态装载依赖、Python 标准库、GDB/Guile/gconv 数据冻结为只读文件集，以外部镜像摘要、源码树摘要和策略摘要启动 bubblewrap。断网，用户目录不挂载，控制器/候选均只读，输出独立；没有下载或安装脚本。Tk GUI 扩展和 site-packages 不属于该开发环境，明确排除，未作为任何门禁必需能力跳过。镜像只服务开发验证，不进入 Agent 依赖或体积预算。

隔离实验曾暴露缺失运行资源：只固定动态库不足以启动 GDB/Guile。缺失 gconv 时 `gdb --version` 在 scm_to_stringn 路径 SIGABRT；A/B 只读挂载确认补字符集数据可消除崩溃，仍需 GDB Guile 模块完成初始化。已将这些数据一起冻结，未修改系统配置或忽略诊断。GNU as 工具镜像 1816 个文件、464103488 字节；前一轮 146 项门禁自测在该隔离环境全部通过，回执位于 `PanGu-artifacts/toolchain/isolated-gas-091mx9lz/output/isolation.json`。源级 C/Assembly 行号、最小双帧回溯、debug/release 重复构建和 PIC 共享链接也包含在内。
