# Linux Release 安装与 MCP HTTP 构建成本（2026-11-19）

当前源码的 CMake Release 实际安装快照，包含 Core、Agent、Services、TUI、resources、stdio MCP；overflow、images、Core proxy HTTP 关闭。对比唯一配置变化为 `PANGU_SERVICES_MCP_HTTP=OFF → ON`，表示编译可用性，不表示该传输已连接服务器。

构建前与安装后逐文件核对157个生产源码/头文件/CMake输入，SHA-256：`c886da9b8ce9cdedebd71a8bf8d7f6221a27de49f85941156d9fbf2660873998`。两组合指纹相同；完整清单、构建配置、安装文件hash、归档hash、strip命令和系统库清单保存在原始JSON。profile目录已恢复HTTP ON，重构建CLI hash与ON安装快照相同。

| 组合 | SDK安装字节 | SDK tar.gz字节 | CLI原始字节 | CLI strip后字节 | strip后CLI gzip字节 |
|---|---:|---:|---:|---:|---:|
| MCP HTTP ON | 4,154,254 | 1,426,368 | 1,404,232 | 1,237,624 | 577,934 |
| MCP HTTP OFF | 4,095,570 | 1,400,120 | 1,382,432 | 1,217,080 | 566,442 |

SDK包括开发库、头文件、许可和CLI；gzip列仅包含主程序，不是完整安装包。SDK安装分别为72/71个文件。35个唯一系统共享库合计26,408,080字节，单列检查、未复制到SDK；未包含外部MCP服务器、搜索程序、信任库、字体等独立部署数据。

MCP HTTP ON的实际增量：SDK安装 **58,684字节**，SDK归档 **26,248字节**，CLI原始 **21,800字节**，strip后 **20,544字节**，strip后CLI gzip **11,492字节**。两组合解析到的系统共享库逐文件相同，因为本默认组合的直接模型已经使用libcurl；不外推其他宿主无需额外依赖。

两组合的已安装原始/strip后CLI均在隔离目录完成JSONL和SQLite的确定性create/open，逐字输出一致；每组合8个命令通过。这不是新真模型或远端TLS验证。

## 已安装CLI/TUI的运行样本

复用 `tools/integration/profile_product.py` 的真实PTY、隔离JSONL会话和确定性模型，每组合3次。每次校验一条输入与assistant保存重开、正常退出和termios恢复，以下为中位数。

| 组合 | 到命令banner(ms) | 空闲RSS(KiB) | 存活进程VmHWM(KiB) | 一轮到usage输出(ms) |

| MCP HTTP ON | 11.56 | 9496 | 9704 | 5.95 |

500ms空闲窗口与短轮次的CPU增量均落在内核计数粒度以下（100Hz，即10ms）；不能据此声称CPU为零。启动含加载器、插件/存储/UI建立及PTY观察，使用暖文件缓存。没有安装或调用MCP HTTP传输，没有工具/网络/大流/多会话成本，也没有Pi产品或其他平台对照；本表不证明活动MCP HTTP成本或两组合的细微性能优劣。
