# Linux Release SDK installation footprint

Measured on 2026-11-15, Linux x86-64, GCC/G++ 16.2.1, CMake Release, unstripped static SDK archives. These are actual installations, not executable-size estimates. Raw file hashes, CMake configuration and resolved shared-library paths are in [product JSON](sdk-linux-2026-11-15.json) and [Core JSON](core-sdk-linux-2026-11-15.json).

| Measurement | Core SDK component | Default Agent/Services/TUI SDK |
|---|---:|---:|
| Installed regular files | 14 | 70 |
| Installed bytes | 547,828 | 3,987,238 |
| Deterministic tar.gz bytes | 223,168 | 1,353,550 |
| CLI bytes | No CLI in this component | 1,346,856 |
| Headers bytes | 42,314 | 123,246 |
| Libraries and CMake metadata bytes | 503,361 | 2,422,893 |
| License notices bytes | 2,153 | 94,243 |
| Resolved CLI shared-library files | Not measured: no CLI | 35 |
| Unique resolved shared-library bytes | Not measured | 26,408,080 |

The default combination selects Agent, Services, TUI, resources and MCP stdio. Overflow classification, proxy HTTP and image codecs are OFF. The SDK archive includes static development libraries, headers, CMake packages, notices and CLI; system shared libraries are inspected with `ldd`, not copied into the archive. The 26,408,080-byte figure includes transitive resolved files and the loader, counted once by resolved path. It is additional deployment context, not a compressed or portable bundle size. On systems where these libraries are already installed it is not all incremental disk usage.

Commands used:

```sh
cmake -S . -B build/product-profile -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=OFF -DPANGU_BUILD_AGENT=ON -DPANGU_BUILD_SERVICES=ON -DPANGU_BUILD_TUI=ON -DPANGU_BUILD_OVERFLOW=OFF -DPANGU_BUILD_PROXY_HTTP=OFF -DPANGU_SERVICES_IMAGES=OFF -DPANGU_SERVICES_MCP=ON -DPANGU_SERVICES_RESOURCES=ON
cmake --build build/product-profile --target pangu_agent_cli --parallel 2
python3 tools/integration/profile_install.py --build-dir build/product-profile --output docs/measurements/sdk-linux-2026-11-15.json
cmake --build build/core-profile --target pangu_core --parallel 2
python3 tools/integration/profile_install.py --build-dir build/core-profile --component Core --output docs/measurements/core-sdk-linux-2026-11-15.json
```

The measurement tool now requires a fresh dedicated `profile-install-all-<label>` or `profile-install-Core-<label>` prefix inside the chosen build directory; it refuses to overwrite an existing prefix. The original measurements above predate labels. Archives stay under that build directory. Use `--label` to preserve previous snapshots. Optional `--strip-tool strip` measures a separate stripped CLI copy without changing installed files.

CLI-only follow-up of the exact baseline executable (matching SHA-256), recorded in [CLI JSON](cli-linux-2026-11-15.json):

| Executable measurement | Bytes |
|---|---:|
| Original CLI | 1,346,856 |
| Original CLI, gzip | 580,158 |
| CLI after `strip --strip-unneeded` | 1,184,248 |
| Stripped CLI, gzip | 547,037 |

These gzip figures contain only the executable, without archive metadata, license notices or shared libraries. They are not installer sizes. The stripped copy completed deterministic create/open with identical output in an isolated agent directory; the original installed executable remained byte-identical. A temporary build-local CMake install fixture exercised the measurement script against this existing executable; no new product SDK build is claimed. LyraPlayer's Android APK and this Linux executable target different platforms and use different system services, so their sizes do not establish a C-versus-C++ size advantage.

The installed Release CLI also completed a deterministic `create --demo` and `open` with an isolated agent directory; output matched exactly. This is a build/install smoke test, not a real-model, terminal or performance result. No startup/RSS/CPU measurement was taken here.

External MCP server executables, dynamically loaded extensions, search programs (`rg`/`fd`), trust stores and terminal/font data are outside this SDK archive. Their deployment costs remain to be measured for a complete distribution. No Pi distribution-size comparison, optional-plugin cost delta, other-platform result or complete C06 acceptance is claimed.
